# Color Palette

### Core Colors
- `#b0d2f7` (Primary blue - buttons, borders)
- `#8fbde8` (Primary blue hover/darker)
- `#ff4444` (Error/close button hover)
- `#ffffff` (White - backgrounds)
- `#000000` (Black - overlay base)

### Neutral/Utility Colors
- `#f0f0f0` (Inactive button background)
- `#f5f5f5` (Disabled button background)
- `#e0e0e0` (Disabled borders, genre tags)
- `#d0d0d0` (Genre tag hover)
- `#cccccc` (Disabled elements)
- `#dddddd` (Default borders)
- `#555` (Default text)
- `#333333` (Hover text)
- `#aaaaaa` (Disabled text)

### Transparent Colors
- `rgba(0, 0, 0, 0.7)` (Popup overlay)
- `rgba(176, 210, 247, 0.1)` (Button hover tint)
- `rgba(176, 210, 247, 0.2)` (Button active tint)
- `rgba(176, 210, 247, 0.3)` (Popup shadow)
- `rgba(255, 255, 255, 0.3)` (Spinner border)

### Status Badge Colors
- **Ongoing:** `#1976d2` (Blue background), White text
- **Completed:** `#4caf50` (Green background), White text
- **WatchList:** `#ff9800` (Orange background), White text
- **Dropped:** `#f44336` (Red background), White text
